> 照这份指引走，10 分钟以内能填完；账号一个工作日内到邮箱。

4. 账号内容：蓝鲸社区版 7.2 在线体验环境（含 CMDB、**作业平台**、权限中心、用户管理、标准运维、节点管理、流程服务）

## 第 2 步：登录后熟悉作业平台（30 分钟）

拿到账号后：
1. 打开邮件里的体验环境地址，用账号密码登录
2. 桌面（PaaS 门户）里找到「作业平台」，点进去
3. 选一个内置演示业务（体验环境一般预置了业务和主机）
4. 对照《2026-08-22-JOB业务理解与测试方案.md》的五条链路，
   把每个页面点一遍：脚本管理 / 快速执行 / 作业模板 / 定时作业 / 账号管理

## 第 3 步：Web 端准备三样"锚点数据"（20 分钟）

测试用例是数据自洽设计，但有三样东西 API 建不了（或必须先在 Web 端有），需要你手工建一次：

1. **一个最简单的作业模板**
   - 作业模板 → 新建 → 模板名随意（如 `zyy测试模板`）
   - 加一个步骤：执行脚本 → 脚本内容写 `echo zyy_template` → 选一个执行账号
   - 保存；保存后会自动派生出默认执行方案（这就是用例要的 job_plan_id）
2. **一台已导入的主机**（体验环境演示业务下一般已有，确认一下即可）
   - 记录该主机 ID → 填到 `job_config.py` 的 `TARGET_HOST_ID`
3. **（可选，端到端用例用）一个 CMDB 动态分组**
   - 打开体验环境的 CMDB → 选同一个业务 → 动态分组 → 新建
   - 条件随意（如：主机名包含某字符），保存后记下分组 ID
   - 填到 `job_config.py` 的 `DYNAMIC_GROUP_ID`

## 第 4 步：拿 ESB 三件套（10 分钟）

测试走的是 ESB 接口（`/api/c/compapi/v2/jobv3/`），需要三样认证：

| 配置项 | 从哪拿 |
|--------|--------|
| `ESB_HOST` | 邮件里给的体验环境网关地址（ESB 网关域名） |
| `BK_APP_CODE` / `BK_APP_SECRET` | 体验环境「开发者中心」→ 创建应用 → 应用基本信息里能看到 |
| `BK_TOKEN` | 蓝鲸「个人中心」登录态 token；拿不到就用浏览器登录后的 cookie 走 Web API（见下面备选） |
| `BK_SCOPE_ID` | 测试业务 ID（作业平台左上角业务选择器里能看到） |

**备选通道**：体验环境若没开 ESB 权限，就用浏览器登录后抓包，
Web 前端调的内部 API 路径与 ESB 一致（只是认证换 cookie），
届时让 AI 帮你把客户端认证层切过去即可（封装层已预留扩展点）。

## 常见问题

- **问卷链接打不开**：从官网 https://bk.tencent.com → 「体验环境」导航进去找申请入口
- **邮件没收到**：查垃圾箱；超过一个工作日没收到，在官网体验环境页找客服/社区反馈
- **忘了在哪看业务 ID**：作业平台页面上方业务切换器，或 CMDB 业务列表
- **不知道执行账号用哪个**：体验环境内置 `root`（Linux）一般可以直接用，`job_config.py` 里已默认填好
