# 执行动态分组

## 功能描述

执行动态分组，返回分组"现在"圈中的主机。坑位：动态分组圈的主机是实时算出来的（按分组条件），不是快照，同一分组两次执行结果可以不同。连块测用途：先查分组圈了哪些主机，再让 JOB 执行这些主机，验证"CMDB 圈人 → JOB 干活"。

## 请求参数

| 字段 | 类型 | 必选 | 描述 |
|---|---|---|---|
| bk_supplier_account | string | 是 | 供应商账号，默认 0 |
| bk_biz_id | int | 是 | 业务 ID |
| id | string | 是 | CMDB 动态分组 ID |
| page | object | 否 | 分页 {start, limit, sort} |
